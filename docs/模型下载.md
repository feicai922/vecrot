# 模型下载与放置

**分发只有一条路线**：代码全部在 GitHub，模型文件全部在网盘。

```powershell
git clone https://github.com/feicai922/vecrot.git
cd vecrot

# 1) 下模型（网盘：[models.zip](https://pan.baidu.com/s/1e6lr0Fk2Ud4lWQYXK58ecA?pwd=c83w) 提取码 c83w）
#    解压得到 models/ 目录，放到仓库里的 vecrot/models/：
#    <仓库根>/
#    ├─ backend/  third_party/  vecrot_qgis/  install.py
#    └─ vecrot/
#       ├─ lib/
#       └─ models/          ← 解压到这里（不要形成 vecrot/models/models/）

# 2) 自己建好 conda 环境（见 docs/安装教程-自建环境.md）
# 3) 装插件
python -X utf8 install.py
```

不想把几个 GB 的权重放进 clone 目录？模型可以放别处：

```powershell
# 方式一：环境变量
setx VECROT_MODELS_ROOT "D:\vecrot-models"

# 方式二：deployment\manifest.json 里
"models_root": "D:\\vecrot-models"
```

`install.py` 会把 `models_root` 一起写进 manifest，插件按它扫模型。

装完检查：

```powershell
python -X utf8 deployment\verify_models.py      # 逐个模型目录检查（含体积下限）
python -X utf8 deployment\add_model_folder.py --list   # 看面板会长什么样
```

## 模型包结构

`models/` 下**每个子目录就是一个可选模型**（面板「模型搭配」下拉框的一项）：

```text
models/
├─ adaptor_sc_055m/          # 轮廓适配器（ScaleCond 0.55M）
├─ official_vocab_635/       # 轮廓基座（635 词表，约 1.5 GB）
├─ base_v1/                  # 可选：重建基座的原料，正常推理不用
├─ detector_strip_s_scene/   # Strip-R-CNN-S + 场景分类（默认推荐）
├─ detector_strip_s/         # 不带场景分类的旧权重
├─ detector_rt-detr_bbox/    # RT-DETR（HF 格式，水平框）
├─ detector_strip_s_fusion/  # 融合数据集重训的 Strip-R-CNN-S
└─ detector_rio_gzda/        # RiO-DETRv2-X（旋转框）
```

前三个是**轮廓链路资产**，会被自动跳过；其余每个检测模型目录都必须有 `model.json`。

## 模型文件夹约定（重要）

面板上的「模型搭配」下拉框，**每一项就是一个文件夹**：`<models 根>/<任意名>/`。
文件夹里的 `model.json` 声明自己是哪个后端、用哪份权重、配哪份配置、几类、阈值多少。所以：

* **加一个模型 = 建一个文件夹**，不用改代码，重启 QGIS 就出现在列表里；
* 权重和配置在同一个 `model.json` 里成对声明，「换了权重忘了换配置」这种错配不可能发生；
* 缺任何必需文件，面板显示 ✗ 并写明缺哪个，不会等作业跑一半才炸。

### 目录形态

```text
models/strip_s_fusion/
├─ model.json                     # 必须
├─ best.pth                       # 权重
└─ strip_s_fusion.py              # 配置（可以用 src: 指向源码树，见下）
```

### model.json 字段

```json
{
  "spec_version": 1,
  "key": "strip_s_fusion",
  "label": "融合数据集 · Strip-R-CNN-S（旋转框）",
  "backend": "strip_s_gzda",
  "num_classes": 1,
  "repo": "repo:third_party/Strip-R-CNN",
  "weights": "best.pth",
  "config": "src:configs/gzda/strip_s_gzda.py",
  "detector_options": {"score_thr": 0.05, "nms_iou": 0.3, "max_per_img": 2000},
  "order": 15,
  "note": "融合数据集重训"
}
```

| 字段 | 必填 | 说明 |
|---|---|---|
| `spec_version` | 否 | 固定 `1`，不匹配会被跳过并说明原因 |
| `key` | 否 | 唯一标识，默认用文件夹名 |
| `label` | 否 | 下拉框显示的文字，默认用文件夹名 |
| `backend` | **是** | `strip_s_gzda` / `mmrotate_obb` / `mmdet_hbb` / `rtdetr_hf` / `rio_detr` / `jsonl` |
| `num_classes` | 否 | 类别数；`strip_s_gzda` 目前恒为 1 |
| `repo` | 否 | 源码树目录（`strip_s_gzda` / `rio_detr` 需要） |
| `weights` | 视后端 | 权重文件；HF 那种「目录即模型」写 `"."` |
| `config` | 视后端 | `.py`（mmcv 系）或 `.yml/.yaml`（RiO-DETR） |
| `detector_options` | 否 | 后端参数，如 `score_thr` / `nms_iou` / `scene_threshold` |
| `vector` | 否 | `{"ckpt": …, "base": …}`，覆盖默认轮廓权重 |
| `order` | 否 | 下拉排序，越小越前（默认 100） |
| `enabled` | 否 | `false` 时不在面板出现 |
| `note` | 否 | 面板上显示的一句说明 |

### 路径写法

| 写法 | 含义 |
|---|---|
| `best.pth` | 相对**本文件夹** |
| `.` | 本文件夹自身（HF 目录即模型） |
| `src:configs/gzda/x.py` | 相对本模型 `repo` 声明的源码树（**最常用**） |
| `repo:third_party/Strip-R-CNN/configs/x.py` | 相对**仓库根** |
| `models:adaptor_sc_055m` | 相对 **models 根**（共用别的文件夹） |
| `D:\...` / `/abs/...` | 绝对路径 |

## 加一个新模型（一条命令）

不用手写 JSON —— 路径前缀和必需字段很容易记错：

```powershell
# 融合数据集重训的 Strip-R-CNN-S（结构与原来一致，只是新权重）
python -X utf8 deployment\add_model_folder.py --name detector_strip_s_fusion ^
    --backend strip_s_gzda ^
    --weights "G:\gzda_fusion\best_mAP_iter_12345.pth" ^
    --config third_party\Strip-R-CNN\configs\gzda\strip_s_gzda.py ^
    --label "融合数据集 · Strip-R-CNN-S（旋转框）" ^
    --num-classes 1 --score-thr 0.05 --order 15

# RiO-DETRv2
python -X utf8 deployment\add_model_folder.py --name detector_rio_gzda --backend rio_detr ^
    --weights "G:\rio\last.pth" ^
    --config third_party\RiODETRv2\configs\rio-gzda\riov2_hgnetv2_x_gzda_12e.yml ^
    --label "RiO-DETRv2-X（融合数据）" --score-thr 0.4 --order 30
```

它会：把权重**复制**进 `<models 根>/<name>/`（`--no-copy` 则写绝对路径）、
把配置写成 `src:configs/gzda/…`（指向源码树，不复制）、写 `model.json`，
最后**回读校验**一遍告诉你缺不缺文件。重启 QGIS 即可在下拉框里选到。

其它用法：

```powershell
python -X utf8 deployment\add_model_folder.py --list     # 看现有文件夹与就绪状态
python -X utf8 deployment\verify_models.py               # 全部模型逐项检查
```

### RiO-DETR 的配置为什么要单独处理

RiO-DETR 的训练配置用 `__include__` 引用同仓库的 `../dataset/xxx.yml`，路径**相对配置文件自己**，
单独拷进模型文件夹就会失效。两种做法：

1. `config` 写 `src:configs/rio-gzda/xxx.yml` 直接指向源码树（源码随 GitHub 分发，最省事）；
2. 用 **展开成单文件**的配置：

```powershell
python -X utf8 deployment\flatten_rio_config.py ^
    --config third_party\RiODETRv2\configs\rio-gzda\riov2_hgnetv2_x_gzda_12e.yml ^
    --out "D:\vecrot-models\detector_rio_gzda\riov2_x_gzda_infer.yaml"
```

展开结果与原配置逐位等价（已实测：同一权重、同一瓦片，输出框完全一致）。

## 维护者：发布网盘模型包

网盘上只放**一个** `models.zip`，解压后就是用户的 `<models 根>`。

```powershell
python -X utf8 deployment\build_models_package.py --out "D:\上传" --zip ^
    --rio-config third_party\RiODETRv2\configs\rio-gzda\riov2_hgnetv2_x_gzda_12e.yml
```

产出 `D:\上传\models\`（骨架）与 `D:\上传\models.zip`。脚本只写
`model.json` / RiO 单文件配置 / 各目录的 `放权重.txt`，**权重由你从本机拷进去**：

| 目录 | 放什么 | 体积 |
|---|---|---|
| `adaptor_sc_055m/` | `trainable.pt` + tokenizer/arch | 小 |
| `official_vocab_635/` | `model.safetensors` + 3 个 json | 约 1.5 GB |
| `detector_strip_s_scene/` | `best_mAP_iter_37620.pth` | 约 540 MB |
| `detector_strip_s/` | `best_mAP_iter_90288.pth` | 约 540 MB |
| `detector_rt-detr_bbox/` | HF 三件套 | 约 306 MB |
| `detector_strip_s_fusion/` | `best.pth`（融合数据重训） | 约 540 MB |
| `detector_rio_gzda/` | `last.pth`（RiO-DETRv2-X） | 约 1.0 GB |
| `base_v1/` | 可选，只影响“重建基座” | 约 1.7 GB |

`model.json` 的内容来自 `deployment/migrate_model_folders.py::LEGACY` 与
`build_models_package.py::NEW_MODELS`，有测试守着两者一致，不会各写一套。

拷完在仓库根跑 `python -X utf8 deployment\verify_models.py` 全绿后压缩上传。

### 源码不进模型包

`third_party/Strip-R-CNN` 与 `third_party/RiO-DETRv2` 都随 Git 分发（后者是 vendored 的
RiO-DETRv2 源码子集，见其 `VECROT_NOTICE.md`），网盘只放权重。

> **许可**：RiO-DETRv2 上游是 **AGPL-3.0**，`third_party/RiO-DETRv2/LICENSE` 原样保留，
> 该目录遵循它而不是父项目的 MIT。源码与本仓库一起公开分发，满足 AGPL 的源码可得义务。

### 旧版模型包怎么办

老包（没有 `model.json`）不是不能用，跑一次就会补上：

```powershell
python -X utf8 deployment\migrate_model_folders.py
```

幂等，只写声明、不动权重。不认识的目录会列出来，让你自己决定怎么配。
