# models 整包下载与放置

网盘分享：[下载 models 文件夹](https://pan.baidu.com/s/1e6lr0Fk2Ud4lWQYXK58ecA?pwd=c83w)

提取码：`c83w`

下载整个 `models` 文件夹，放到 **仓库根目录下的 `vecrot/`**。压缩包则先解压，避免形成 `vecrot/models/models/`。模型包和代码使用同一发布版本；已有同名文件先备份，再合并对应版本的配置。无需把基座放入 work 目录。

```text
<仓库根>/
├─ install.py
├─ backend/
├─ vecrot_qgis/
└─ vecrot/
   ├─ lib/
   └─ models/                        ← 网盘下载的整个文件夹
      ├─ adaptor_sc_055m/            # 适配器、tokenizer、arch.json
      ├─ official_vocab_635/         # 必需：完整重建基座目录
      │  ├─ model.safetensors
      │  ├─ config.json
      │  └─ tokenizer.json
      ├─ detector_strip_s_scene/     # 默认检测器
      │  ├─ best_mAP_iter_37620.pth
      │  └─ strip_s_gzda_scene.py
      ├─ detector_strip_s/
      │  └─ Strip-R-CNN/             # 定制源码，不是只有权重
      │     └─ configs/gzda/         # 含 gzda_dataset、scene_branch、scene_hooks
      ├─ detector_rt-detr_bbox/      # 可选：RT-DETR 完整 HF 目录
      └─ base_v1/                    # 可选：重建原料，正常推理不用
```

检测源码必须是配套的定制版本。只下载 `.pth` 或随意 git clone 公开基础版都不能替代完整模型包。大型模型由网盘分发；适配器和场景配置也随代码保留，便于核对版本。

在 PowerShell 7 中检查：

```powershell
python -X utf8 deployment/verify_models.py
python -X utf8 install.py --check
python -X utf8 install.py
```

模型检查核对必需文件、定制模块与最小体积，不加载模型，也不能替代真实推理验证。三个外部 conda 环境仍需按 [安装教程](安装教程-自建环境.md) 建立。安装、卸载、调试命令见 [插件管理](插件安装卸载与本机调试.md)。
