# 插件安装、卸载与本机调试

仓库名为 `vecrot`，可放在任意盘符和父目录；无需建立作者的目录。所有命令在克隆后的仓库根目录（含 install.py）使用外部 Python 执行，不向 QGIS Python 安装依赖。先关闭目标 profile 的 QGIS，避免已加载模块或作业占用文件。

## 安装和更新

先下载 [models 整包](https://pan.baidu.com/s/1e6lr0Fk2Ud4lWQYXK58ecA?pwd=c83w)（提取码 `c83w`）到 `vecrot/models/`，建立外部环境，再执行：

```powershell
python -X utf8 install.py --check
python -X utf8 install.py
```

检查失败不会安装。检查只做路径、文件和环境存在性检查，不执行模型推理。安装会生成本机 manifest、复制薄插件并为指定 profile 设置启用状态及 manifest 路径。旧插件会移入该 profile 的 `vecrot-plugin-backups/`，不会直接删除；更新失败时恢复原插件目录。QGIS 设置写入失败会返回非零并说明文件操作已完成，不能当成全成功。

## 卸载

```powershell
python -X utf8 install.py --uninstall
```

等价的独立入口：`python -X utf8 uninstall.py`，同样支持 `--qgis-profile`、`--profiles-path` 和 `--no-qgis-settings`。

卸载把 `python/plugins/vecrot_qgis` 移出加载目录并备份，停用该 profile 的插件，移除该 profile 保存的 manifest 路径。重复卸载可安全执行。不删除仓库、models、conda 环境、作业和最终成果。开发链接移走的是链接本身，不会移动或删除真实源码。

## 本机调试

建议先在 QGIS 中建立名为 `vecrot-dev` 的独立用户配置 / profile，再关闭 QGIS：

```powershell
python -X utf8 install.py --qgis-profile vecrot-dev --dev --ui-only
```

`--dev` 将 profile 中的插件目录链接到当前仓库的 `vecrot_qgis`，无需每次复制；Windows 需启用开发者模式或使用管理员终端。创建链接失败会返回错误并恢复旧插件，不静默改成复制。

`--ui-only` 允许模型和环境未齐时先安装界面，不代表提取功能已就绪。模型测试应去掉该选项并先通过检查。

没有链接权限时用复制模式调试：

```powershell
python -X utf8 install.py --qgis-profile vecrot-dev --ui-only
```

复制模式修改源码后重新安装；链接模式修改后重启 QGIS 或通过插件重载工具重新加载。修改后端只需启动新的作业进程。调试时避免遗留旧作业；改变模型输入或协议后使用新 job_id。

卸载调试 profile：

```powershell
python -X utf8 install.py --qgis-profile vecrot-dev --uninstall
```

## 非标准目录与手动启用

`--profiles-path` 指向包含 default、vecrot-dev 等子目录的 profiles 根目录：

```powershell
python -X utf8 install.py --profiles-path 'E:\QGIS配置\profiles' --qgis-profile vecrot-dev --ui-only
```

QGIS 本身也必须使用相同的 profile 根；可在 QGIS 的“打开当前配置文件夹”确认真实位置。脚本拒绝用路径分隔符或 `..` 充当 profile 名称。

找不到 QGIS 安装根时，可以设置 `$env:QGIS_PREFIX` 后重试。安装器仅借用 QGIS 的 Qt 设置 API 更新目标 profile 的 INI，不加载模型。如果自动配置不可用：

```powershell
python -X utf8 install.py --ui-only --no-qgis-settings
python -X utf8 install.py --uninstall --no-qgis-settings
```

该模式只操作插件文件。请在 QGIS 插件管理器中手动启用/停用，并在 Vecrot 高级设置选择当前仓库 `deployment/manifest.json`。卸载后旧启用设置可能仍在，但模型和源码不会被删除。

解释器路径优先使用 VECROT_PY_COORDINATOR、VECROT_PY_DETECTOR、VECROT_PY_VECTOR；未显式覆盖时保留已有有效 manifest 配置，再尝试模板和自动探测。历史 `--check-only`、`--skip-envs` 兼容，其中源码版不负责解包环境。

目前自动配置主要按 QGIS 3.x profile 布局处理；新电脑首次安装仍应实际验证。备份可人工清理，脚本不自动清理。

## 更换仓库位置

安装器使用自身文件位置定位仓库，与终端最初工作目录无关。安装完成后生成的 manifest 含当前机器绝对路径；移动或重命名仓库后，在新位置重新安装，刷新模型路径和开发链接。本机 `deployment/manifest.json` 不随 Git 分发，接收方只使用通用模板生成自己的配置。
